# Challenge14_Spotify

Repositório da entrega do grupo 06 do desafio "Clonando o Spotify" — projeto acadêmico/de turma em **UIKit** para iOS.

## Sobre

Base de projeto iOS em UIKit (`AppDelegate` + `SceneDelegate`, sem SwiftUI e sem Storyboard como fluxo principal) criada como ponto de partida para a implementação da interface do Spotify pelo grupo. No estado atual do repositório, o `ViewController` é o padrão gerado pelo Xcode, ainda sem a tela implementada.

## Estrutura

```
CloningSpotify/
└── CloningSpotify/
    ├── AppDelegate.swift
    ├── SceneDelegate.swift
    ├── ViewController.swift
    └── Assets.xcassets/
```

## Tecnologias

- Swift, UIKit
- Ciclo de vida via `AppDelegate` / `SceneDelegate` (sem SwiftUI App lifecycle)

## Requisitos

- iOS (simulador ou dispositivo)
- Xcode

## Como rodar

1. Clone o repositório
2. Abra `CloningSpotify/CloningSpotify.xcodeproj` no Xcode
3. Selecione um simulador de iOS
4. `Cmd + R` para rodar
